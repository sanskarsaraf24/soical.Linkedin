## Key Principles Across All Brands

### Always
✓ Border-radius: 0 (squared corners only)
✓ Grid-based layout (CSS Grid or Flexbox)
✓ All text ≥32px
✓ Whitespace as design element
✓ Colors from strict palette only
✓ 1–2px thin borders (never thick)
✓ Maximum 3 colors on card

### Never
✗ Rounded corners
✗ Gradients
✗ Drop shadows (use borders instead)
✗ Decorative shapes
✗ Stock photos or illustrations
✗ Semi-transparent overlays (except 8–12% accent fills)
✗ Text overlaying complex backgrounds

## Quick Identifier

If you see a post that says **"Look at this post—what archetype is it?"** here's how to tell:

| Archetype | Identifier |
|-----------|-----------|
| A | Two columns, large text left, accent element right |
| B | Centered headline, accent shape bottom-right, editorial feel |
| C | Centered everything, divider line, max whitespace |
| D | Grid of data/boxes, accent shape background, insight-focused |

---

## Testing Template

When you generate a new post, check this checklist:

- [ ] Archetype is clearly one of A, B, C, or D
- [ ] Layout is different from the previous post
- [ ] All text is ≥32px (measure in DevTools)
- [ ] Colors match brand palette exactly
- [ ] No rounded corners (border-radius: 0)
- [ ] No gradients
- [ ] No decorative shapes
- [ ] Whitespace feels intentional, not empty
- [ ] Professional & premium (not generic)
